# AIA API 术语表 / Translation Glossary

Terminology for the AIA-specific fork; retained upstream third-party notices are not product UI.

| Term | English | Context |
| --- | --- | --- |
| 统一登录 | Single sign-on | AIA Forum OIDC |
| 平台 API 令牌 | Platform API token | API credential issued by AIA |
| 上游开发者密钥 | Upstream developer key | Provider credential contributed by a user |
| 贡献密钥共享池 | Contributed-key pool | Shared routing with per-key budget |
| 独立模型目录 | Independent model catalog | API model IDs maintained separately from upstream endpoints |
| 每日预算 | Daily contribution budget | Bound on contributed-key usage, measured in platform quota units |
| 额度 | Credits / quota | Internal platform usage balance, not money |
| 兑换码 | Redemption code | Code redeemable for quota; not a cash top-up |
| 上游端点 | Provider endpoint | Admin-approved HTTPS developer API endpoint |
| 冷却 | Cooldown | Temporary withdrawal after 429 or insufficient upstream quota |
