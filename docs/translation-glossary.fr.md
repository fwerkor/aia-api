# Glossaire AIA API (français)

Terminology for the AIA-specific fork; retained upstream third-party notices are not product UI.

| Term | English | Context |
| --- | --- | --- |
| Connexion unique | Single sign-on | AIA Forum OIDC |
| Jeton API de la plateforme | Platform API token | Identifiant du client de la passerelle |
| Clé API du fournisseur | Upstream developer API key | Secret fourni et chiffré |
| Réserve de clés partagées | Contributed-key pool | Clés validées et budget journalier |
| Crédits | Platform quota | Solde interne, pas de monnaie |
| Code de crédit | Redemption code | Crédits sans paiement en ligne |
| Modèle | Model code | Identifiant du catalogue AIA |
