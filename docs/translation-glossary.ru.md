# Глоссарий AIA API (русский)

Terminology for the AIA-specific fork; retained upstream third-party notices are not product UI.

| Term | English | Context |
| --- | --- | --- |
| Единый вход | Single sign-on | AIA Forum OIDC |
| Токен платформы | Platform API token | Выдан для вызовов AIA API |
| Ключ поставщика | Upstream developer key | Внесенный и зашифрованный ключ |
| Пул общих ключей | Contributed-key pool | Проверенные ключи с ежедневным лимитом |
| Кредиты | Platform quota | Внутренний баланс, не денежные средства |
| Код пополнения баланса | Redemption code | Обмен на кредиты без денежных платежей |
| Модель | Model code | Идентификатор каталога AIA |
